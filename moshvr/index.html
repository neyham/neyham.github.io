moshVR

A native mosh and SSH terminal for Meta Quest. The client runs on the headset; the shell runs on your server. No PC streaming or companion app. Confirm text in the composer before anything is sent to the host.

Work in a Home panel or a movable immersive workspace. Switch sessions, scroll with the controller, and use the Quest keyboard plus terminal extra keys. Keep the room in view with passthrough, or use the digital-rain environment.

Optional cloud speech puts a transcription in the composer. You need your own API key, endpoint consent, and confirmation that you are 18 or older. MIC STOP uploads audio to the provider you configured. The terminal works without a microphone.

Source is public under GPLv3. This is an Early Access development build: debug-signed, not a long-lived release key. Sideload needs Developer Mode. A reachable SSH host is required; mosh also needs mosh-server and UDP. A SideQuest listing is pending review and is not public yet.
